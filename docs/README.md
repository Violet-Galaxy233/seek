# Seek 文档索引

此目录保存项目长期产品和技术上下文。新开发环境应先阅读根目录 `AGENTS.md`，再按下列顺序阅读。

1. [产品说明](product.md)：用户问题、产品原则、MVP、长期范围和验收指标。
2. [架构说明](architecture.md)：当前实现、目标架构、领域模型和混合检索。
3. [数据策略](data-strategy.md)：全球曲库、流派覆盖、数据来源、许可和扩容路线。
4. [微信小程序前端](frontend.md)：页面、状态、组件、交互和视觉规范。
5. [赛事计划](competition.md)：2026 微信小程序开发大赛要求、评分策略和时间安排。
6. [关键决策](decisions.md)：对话中已经确认的范围、模型、数据和产品方向。
7. [30 个验收案例](acceptance-cases.md)：真实模糊记忆测试集的结构、分组和判定方法。
8. [开发交接](handoff.md)：当前代码与资产状态、运行方法、已知限制和下一步任务。

## 阅读原则

- `AGENTS.md` 保存每次开发都必须遵守的稳定规则。
- `product.md` 和 `architecture.md` 是产品与技术事实来源。
- `handoff.md` 反映当前阶段状态，会频繁更新。
- 模型、封面、数据库和索引不进入 Git，服务器恢复方式见交接文档。
